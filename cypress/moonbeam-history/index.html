Historical archive

From Moonbeam to today

Cypress has a historical Moonbeam phase. Moonbeam is no longer within Cypress's active product scope, which is now Base, Polkadot Hub and Hydration. This archive preserves older records; it does not present historical networks or guidance as current.

Archive status: historical documentation, not a current network or migration guide.

How to read this archive

Evidence categories

Repository record

Content, routes or version history directly retained in this repository.

Project-authored record

A historical statement made by Cypress, presented as the project's account rather than independent proof.

Retained snapshot

An archived image or record preserved by Cypress, with any missing capture context stated plainly.

Unresolved

A claim that is not published as fact until its date, source or on-chain evidence can be verified.

Names in the record

Terminology across periods

Repository material has used Cypress for the project and community, and Cypress Capital in older project material. CP and Token CP are the main names attached to the historical Moonbeam token record.

Older material also contains the names CypressCoin and CPcoin/CPCoin. Current Cypress material uses dotCP for an asset associated with Cypress in the Polkadot ecosystem. This archive does not assert technical or token continuity among CypressCoin, CPcoin/CPCoin and dotCP.

Present scope

Transition to current Cypress

Cypress currently focuses on Base, Polkadot Hub and Hydration. This archive records the earlier Moonbeam phase; it does not provide migration instructions, conversion mechanics or current transaction guidance.
